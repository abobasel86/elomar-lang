# 4. القوائم والقواميس والمجموعات

## القوائم

القائمة تحفظ قيمًا من نوع واحد بترتيب:

```elomar
fn main() {
    let الدرجات = [90, 75, 60]
    print(الدرجات[0], الدرجات.length)
    print(الدرجات.first(), الدرجات.last())     // Some(90) Some(60)
    print(الدرجات.contains(75), الدرجات.sorted())

    var الأسماء: List<String> = []
    الأسماء.push("لينا")
    الأسماء.push("عمر")
    print(الأسماء, الأسماء.join(" و"))
}
```

القراءة خارج حدود القائمة، مثل `الدرجات[9]`، توقف البرنامج بخطأ واضح. أما `first()`
و`last()` فتعيدان `Option`، وهذا آمن حتى مع القائمة الفارغة.

## العمل على كل عنصر

الدوال المكتوبة مباشرة بين `|...|` تسمى **دوال مجهولة** (closures):

```elomar
fn main() {
    let الأسعار = [12.5, 3.0, 8.25]
    print(الأسعار.map(|p| p * 2.0))
    print(الأسعار.filter(|p| p > 5.0))
    print(الأسعار.sum(), الأسعار.max())
    print(الأسعار.fold(0.0, |المجموع, p| المجموع + p))
    print(الأسعار.any(|p| p > 10.0), الأسعار.all(|p| p > 1.0))
    print(الأسعار.find(|p| p < 5.0))
    print(الأسعار.sort_by(|p| -p))
}
```

ودوال مفيدة أخرى: `take(n)` و`skip(n)` و`unique()` و`reverse()` و`enumerate()`
و`chunks(n)` و`flat_map(f)` و`group_by(f)`:

```elomar
fn main() {
    let الكلمات = ["تفاح", "تمر", "برتقال", "موز"]
    for عنصر in الكلمات.enumerate() {
        print(عنصر.index, عنصر.value)
    }
    print(الكلمات.group_by(|w| w.slice(0, 1)))
    print([1, 2, 3, 4, 5].chunks(2))
}
```

## القواميس (Map)

القاموس يربط مفاتيح بقيم:

```elomar
fn main() {
    var المخزون = ["تفاح": 10, "إجاص": 4]
    المخزون["تين"] = 7
    المخزون["تفاح"] = المخزون["تفاح"] - 1
    print(المخزون["تفاح"], المخزون.length)
    print(المخزون.get("كيوي"))               // None: غير موجود
    print(المخزون.get_or("كيوي", 0))         // 0
    for المفتاح in المخزون.keys() {
        print("{المفتاح}: {المخزون[المفتاح]}")
    }
}
```

`المخزون["كيوي"]` لمفتاح غير موجود توقف البرنامج؛ فاستخدم `get` أو `get_or` عندما
قد يغيب المفتاح. والقاموس الفارغ يُكتب `[:]`.

## المجموعات (Set)

المجموعة تحفظ كل قيمة مرة واحدة فقط:

```elomar
fn main() {
    var شوهد = set(["أ", "ب"])
    شوهد.add("أ")
    شوهد.add("ج")
    print(شوهد, شوهد.contains("ب"))
    let أخرى = set(["ج", "د"])
    print(شوهد.union(أخرى), شوهد.intersection(أخرى))
}
```
