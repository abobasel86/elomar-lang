# 4. القوائم والقواميس والمجموعات

## القوائم

القائمة تحفظ قيمًا من نوع واحد بترتيب:

```elomar
fn main() {
    let الدرجات = [90, 75, 60]
    print(الدرجات[0], الدرجات.length)
    print(الدرجات.first(), الدرجات.last())     // Some(90) Some(60)
    print(الدرجات.contains(75), الدرجات.sorted())

    var الأسماء: List<String> = []
    الأسماء.push("لينا")
    الأسماء.push("عمر")
    print(الأسماء, الأسماء.join(" و"))
}
```

القراءة خارج حدود القائمة، مثل `الدرجات[9]`، توقف البرنامج بخطأ واضح. أما `first()`
و`last()` فتعيدان `Option`، وهذا آمن حتى مع القائمة الفارغة.

## العمل على كل عنصر

الدوال المكتوبة مباشرة بين `|...|` تسمى **دوال مجهولة** (closures):

```elomar
fn main() {
    let الأسعار = [12.5, 3.0, 8.25]
    print(الأسعار.map(|p| p * 2.0))
    print(الأسعار.filter(|p| p > 5.0))
    print(الأسعار.sum(), الأسعار.max())
    print(الأسعار.fold(0.0, |المجموع, p| المجموع + p))
    print(الأسعار.any(|p| p > 10.0), الأسعار.all(|p| p > 1.0))
    print(الأسعار.find(|p| p < 5.0))
    print(الأسعار.sort_by(|p| -p))
}
```

ويمكن تمرير الدوال المدمجة بالطريقة نفسها:

```elomar
fn main() {
    print(["3", "x", "12"].map(parse_int))               // [Some(3), None, Some(12)]
    print([-2, 5, -7].map(abs), [4, 9, 2].fold(0, max))  // [2, 5, 7] 9
    let قل = print
    قل("تم")
}
```

ودوال مفيدة أخرى: `take(n)` و`skip(n)` و`unique()` و`reverse()` و`enumerate()`
و`chunks(n)` و`flat_map(f)` و`group_by(f)`:

```elomar
fn main() {
    let الكلمات = ["تفاح", "تمر", "برتقال", "موز"]
    for عنصر in الكلمات.enumerate() {
        print(عنصر.index, عنصر.value)
    }
    print(الكلمات.group_by(|w| w.slice(0, 1)))
    print([1, 2, 3, 4, 5].chunks(2))
}
```

واجمع قائمتين بـ `zip`، وانظر إلى العناصر المتجاورة بـ `windows(n)`، واجمع أو اختر حسب
مفتاح بـ `sum_by` و`max_by` و`min_by`:

```elomar
type Student = { name: String, grade: Int }

fn main() {
    let الأسماء = ["لينا", "عمر"]
    let الدرجات = [91, 55]
    for (الاسم, الدرجة) in الأسماء.zip(الدرجات) {
        print("{الاسم}: {الدرجة}")
    }
    print([3, 5, 9].windows(2))              // [[3, 5], [5, 9]]

    let الصف: List<Student> = [{ name: "لينا", grade: 91 }, { name: "عمر", grade: 55 }]
    print(الصف.sum_by(|s| s.grade))          // 146
    print(الصف.max_by(|s| s.grade).map(|s| s.name))   // Some("لينا")
}
```

وللعمل الثقيل على قائمة طويلة، `par_map(f)` تعطي القائمة نفسها التي تعطيها `map(f)`، لكنها توزع العمل
على أنوية المعالج. تفعل ذلك فقط إن كانت `f` تحسب لا غير: لا تطبع ولا تقرأ إدخالًا ولا تستخدم ملفات أو قاعدة
بيانات أو أرقامًا عشوائية. وإلا نُفذت مثل `map`، فلا تتغير النتيجة أبدًا:

```elomar
fn الخطوات(n: Int) -> Int {
    var x = n
    var العدد = 0
    while x != 1 {
        if x % 2 == 0 {
            x = x div 2
        } else {
            x = 3 * x + 1
        }
        العدد += 1
    }
    return العدد
}

fn main() {
    var الأعداد: List<Int> = []
    for i in 1..=100000 {
        الأعداد.push(i)
    }
    print(الأعداد.par_map(الخطوات).sum())   // مثل map، وأسرع بعدة مرات
}
```

وبالطريقة نفسها تعطي `par_filter(f)` ما تعطيه `filter(f)`. أما `par_fold(init, f)` فتطوي القائمة أجزاءً على
الأنوية، ثم تطوي نتائج الأجزاء معًا، لذلك تأخذ `f` عنصرين وتُرجع قيمة من نوعهما. وإن كانت `f` تعطي النتيجة
نفسها مهما جُمّعت العناصر، كالجمع و`max` ووصل النصوص، فالنتيجة هي نتيجة `fold`:

```elomar
fn main() {
    var الأعداد: List<Int> = []
    for i in 1..=100000 {
        الأعداد.push(i)
    }
    let السباعية = الأعداد.par_filter(|n| n % 7 == 0)
    print(السباعية.par_fold(0, |a, b| a + b))   // 714264285
}
```

وكذلك تعطي `par_any` و`par_all` و`par_find` و`par_count` و`par_sort_by` و`par_flat_map` و`par_group_by` و`par_sum_by`
و`par_min_by` و`par_max_by` ما تعطيه الدوال نفسها بلا `par_`، مع توزيع العمل على الأنوية. ويشرح درس
[السرعة والتوازي](11-speed.html) أي الدوال تعمل على الأنوية وكيف تجعل برامجك سريعة.

## القواميس (Map)

القاموس يربط مفاتيح بقيم:

```elomar
fn main() {
    var المخزون = ["تفاح": 10, "إجاص": 4]
    المخزون["تين"] = 7
    المخزون["تفاح"] = المخزون["تفاح"] - 1
    print(المخزون["تفاح"], المخزون.length)
    print(المخزون.get("كيوي"))               // None: غير موجود
    print(المخزون.get_or("كيوي", 0))         // 0
    for المفتاح in المخزون.keys() {
        print("{المفتاح}: {المخزون[المفتاح]}")
    }
}
```

`المخزون["كيوي"]` لمفتاح غير موجود توقف البرنامج؛ فاستخدم `get` أو `get_or` عندما
قد يغيب المفتاح. والقاموس الفارغ يُكتب `[:]`.

وللقواميس `filter` و`any` و`all` و`count` بدالة تأخذ المفتاح والقيمة، و`map_values` تغيّر كل القيم:

```elomar
fn main() {
    let الأسعار = ["tea": 4, "coffee": 7, "juice": 5]
    print(الأسعار.filter(|الاسم, السعر| السعر > 4))   // ["coffee": 7, "juice": 5]
    print(الأسعار.map_values(|السعر| السعر * 2))      // ["coffee": 14, "juice": 10, "tea": 8]
    print(الأسعار.any(|الاسم, السعر| السعر > 6), الأسعار.count(|الاسم, السعر| الاسم.length > 3))   // true 2
}
```

## المجموعات (Set)

المجموعة تحفظ كل قيمة مرة واحدة فقط:

```elomar
fn main() {
    var شوهد = set(["أ", "ب"])
    شوهد.add("أ")
    شوهد.add("ج")
    print(شوهد, شوهد.contains("ب"))
    let أخرى = set(["ج", "د"])
    print(شوهد.union(أخرى), شوهد.intersection(أخرى))
}
```

وللمجموعات أيضًا `filter` و`map` و`any` و`all` و`count`؛ و`map` تعطي مجموعة، فتُحفظ النتائج المتساوية مرة واحدة:

```elomar
fn main() {
    let الأعداد = set([12, 7, 30, 9])
    print(الأعداد.filter(|n| n % 2 == 0))   // set([12, 30])
    print(الأعداد.map(|n| n % 3))           // set([0, 1])
}
```
