# 9. الذكاء الاصطناعي في اللغة

في Elomar-Lang، سؤال نموذج ذكاء اصطناعي استدعاء عادي له نوع. تحدد النوع الذي تريده،
وتتحقق اللغة من إجابة النموذج قبل أن يراها برنامجك.

## أول استدعاء، بدون إنترنت

النموذج المدمج `mock` لا يحتاج حسابًا ولا يكلف شيئًا، فهو مثالي للتعلم والاختبارات:

```elomar
use std.ai

type Summary = { title: String, points: List<String> }

async fn main() {
    match await ai.infer<Summary>(
        model: "mock",
        instructions: "لخّص النص في عنوان ونقاط قصيرة",
        input: "Elomar-Lang لغة برمجة فيها الذكاء الاصطناعي جزء من اللغة."
    ) {
        Ok(s) => print("العنوان: {s.title}، النقاط: {s.points.length}")
        Err(e) => print("فشل: {e.kind()}")
    }
}
```

الجديد هنا:

- `async fn main` و`await`: استدعاء الذكاء الاصطناعي يأخذ وقتًا، فيعيد **مستقبلًا**
  (future) تنتظره بـ `await`.
- `ai.infer<Summary>` تطلب `Summary`. إن أجاب النموذج بشيء آخر تحصل على
  `Err(AIError.InvalidStructuredOutput(...))`، ولا تحصل أبدًا على سجل ناقص.
- الأخطاء قيم من النوع `AIError`: `Timeout` و`RateLimited` و`Authentication`
  و`PolicyDenied` وغيرها، وتطابقها كأي نوع معدود.

## نموذج حقيقي

صِف النموذج في `elomar.toml` وأعطه اسمًا يستخدمه كودك:

```toml
[ai.models."support.classifier"]
provider = "anthropic"             # أو "openai"
model = "claude-opus-5-5"
api_key_env = "ANTHROPIC_API_KEY"  # المفتاح يبقى في متغير البيئة

[ai.policy]
max_calls_per_run = 20

[permissions]
network_hosts = ["api.anthropic.com"]
```

```elomar
use std.ai

enum Priority { Low, Normal, Urgent }
type Ticket = { category: String, priority: Priority, summary: String }

pub async fn classify(text: String) -> Result<Ticket, AIError> !{ai, net} {
    return await ai.infer<Ticket>(
        model: "support.classifier",
        instructions: "صنّف طلب الدعم.",
        input: text,
        timeout: 30s
    )
}

async fn main() {
    match await classify("خُصم المبلغ مرتين من حسابي!") {
        Ok(t) => print("[{t.priority}] {t.category}: {t.summary}")
        Err(e) => print("فشل الذكاء الاصطناعي ({e.kind()}): {e.message()}")
    }
}
```

لاحظ `!{ai, net}`: الدالة العامة التي تستدعي نموذجًا سحابيًا يجب أن تصرّح بذلك، فيعرف
كل من يقرأ `classify` أنها تستخدم الذكاء الاصطناعي والشبكة.

والأمان مدمج: المفتاح يُقرأ من البيئة ولا يظهر في الرسائل، ولا يُتصل إلا بالمضيفات
المذكورة، وحد الاستدعاءات يوقف أي حلقة منفلتة. ويُرسل `input` كبيانات، ويُطلب من النموذج
ألا يتبع تعليمات مكتوبة داخلها.

وكل من يشغّل برنامجك يستخدم مفتاحه هو: يضعه في نافذته قبل التشغيل (`$env:ANTHROPIC_API_KEY = "..."` في PowerShell،
و`export ANTHROPIC_API_KEY=...` في غيرها). لا يحمل `elomar.toml` ولا الكود أي مفتاح، فمشاركة المشروع لا تشارك مفتاحك.
وتثق اتصالات HTTPS أيضًا بالشهادات التي يثق بها نظامك، فتعمل الاستدعاءات خلف برامج الحماية وخوادم الشركات الوسيطة
التي تفحص الاتصالات الآمنة. وإن رفض المزود معرّف النموذج، فالخطأ يطلب مراجعة `model` في `elomar.toml`.

## نموذج مجاني على جهازك

يشغّل [Ollama](https://ollama.com) نماذج مفتوحة على جهازك أنت، دون مفتاح ودون كلفة لكل استدعاء. ثبّته ونزّل نموذجًا
(`ollama pull qwen2.5:7b`، و`ollama pull nomic-embed-text` للتضمين)، ثم وجّه نموذجًا إليه:

```toml
[ai.models.local]
provider = "openai"
model = "qwen2.5:7b"
base_url = "http://localhost:11434/v1"

[permissions]
network_hosts = ["localhost:11434"]
```

ولا يتغير كودك: `ai.infer<Ticket>("local", ...)` و`ai.stream` و`ai.search` تعمل كما هي. ولا يلزم مفتاح لخادم على
`localhost`. انظر [`examples/ai-local`](https://github.com/abobasel86/elomar-lang/tree/main/examples/ai-local).

## طلبات كثيرة في وقت واحد

`await all([...])` تنتظر عدة استدعاءات وتعيد نتائجها بالترتيب. والاستدعاءات الممررة مباشرة تُرسل
في الوقت نفسه، فتستغرق عشرة طلبات وقت طلب واحد تقريبًا:

```elomar
use std.ai

async fn main() {
    let النصوص = ["رائع", "تعطل", "مقبول"]
    let الإجابات = await all(النصوص.map(|t| ai.infer<String>("mock", "صنّف المزاج", t)))
    for عنصر in النصوص.enumerate() {
        print(عنصر.value, الإجابات[عنصر.index])
    }
}
```

ويمر كل استدعاء بفحص الصلاحيات وحد الاستدعاءات، ولكل إجابة `Result` خاص بها، فلا يخفي فشل
أحدها البقية.

## الإجابة وهي تُكتب: `ai.stream`

تعطي `ai.stream` الإجابة قطعةً قطعة بينما يكتبها النموذج، فتظهر الإجابة الطويلة فورًا بدل انتظار اكتمالها. الدالة التي
تمررها تأخذ كل قطعة، والنتيجة النص كله:

```elomar
use std.ai

async fn main() {
    let القصة = await ai.stream("mock", "اكتب قصة قصيرة.", "قطة والبحر", |قطعة| {
        print(قطعة)
    })
    match القصة {
        Ok(النص) => print("{النص.length} حرفًا في المجموع")
        Err(e) => print("فشل: {e.message()}")
    }
}
```

نماذج OpenAI وClaude تبث الإجابة فعلًا، والنموذج الوهمي يبث إجابته كلمةً كلمة.

## المعنى أرقامًا: `ai.embed`

تحوّل `ai.embed` النص إلى قائمة أرقام (*تضمين* أو embedding) يدل اتجاهها على معنى النص، وتقارن `ai.similarity`
بين اثنين منها: 1 يعني الاتجاه نفسه، و0 لا علاقة. وهكذا يكون البحث بالمعنى بدل الكلمات المطابقة:

```elomar
use std.ai

async fn main() {
    let الملاحظات = ["feeding the cat", "paying the electricity bill", "the cat sleeps on the mat"]
    var المتجهات: List<List<Float>> = []
    for n in الملاحظات {
        match await ai.embed("mock", n) {
            Ok(v) => المتجهات.push(v)
            Err(e) => print(e.message())
        }
    }
    match await ai.embed("mock", "where the cat sleeps") {
        Ok(q) => {
            let الدرجات = المتجهات.par_map(|v| ai.similarity(q, v))
            print(الدرجات.map(|s| s.round_to(2)))   // [0.58, 0.25, 0.71]
        }
        Err(e) => print(e.message())
    }
}
```

النموذج الوهمي يقارن الكلمات، فيعمل دون إنترنت في الاختبارات. أما نموذج تضمين حقيقي (`provider = "openai"` مع نموذج
مثل `text-embedding-3-small`) فيفهم المترادفات واللغات الأخرى أيضًا. نماذج Claude لا تصنع تضمينات، فتفشل
`ai.embed` معها بـ`UnsupportedCapability`. و`ai.similarity` حساب عادي، فتعمل داخل دوال `par_` على كل الأنوية.

ولتضمين نصوص كثيرة انتظرها معًا: يرسل `await all` الاستدعاءات إلى كل نموذج دفعة واحدة، ونموذج OpenAI يضمّن حتى 256 نصًا
في طلب واحد:

```elomar
use std.ai

async fn main() {
    let الملاحظات = ["feeding the cat", "paying the bill", "the cat sleeps"]
    let المتجهات = await all(الملاحظات.map(|n| ai.embed("mock", n)))
    print(المتجهات.count(|r| r.is_ok()))   // 3
}
```

و`ai.search` تفعل هذا كله في استدعاء واحد: تضمّن السؤال والنصوص معًا وتعيد النصوص مع درجاتها، الأقرب أولًا:

```elomar
use std.ai

async fn main() {
    let الملاحظات = ["feeding the cat", "paying the electricity bill", "the cat sleeps on the mat"]
    match await ai.search("mock", "where the cat sleeps", الملاحظات) {
        Ok(النتائج) => {
            for h in النتائج.take(2) {
                print(h.text, h.score.round_to(2))
            }
            // the cat sleeps on the mat 0.71
            // feeding the cat 0.58
        }
        Err(e) => print(e.message())
    }
}
```

وإن كنت تبحث في الملاحظات نفسها مرة بعد مرة، فاحفظ متجهاتها في ملف، ولن يُرسل نص ضُمّن من قبل مرة أخرى:

```toml
[ai.cache]
embeddings = "embeddings.cache.json"
```

## الأدوات: دع النموذج يستدعي دوالك

مع `ai.run` يمكن للنموذج أن يستدعي الدوال التي تذكرها، ولا شيء غيرها:

```elomar
use std.ai

type Student = { name: String, grade: Int }
type Answer = { answer: String }

let STUDENTS = [{ name: "لينا", grade: 91 }, { name: "عمر", grade: 55 }]

fn find_student(name: String) -> Option<Student> {
    return STUDENTS.find(|s| s.name == name)
}

async fn main() {
    match await ai.run<Answer>(
        model: "mock",
        instructions: "أجب عن أسئلة الصف مستخدمًا الأدوات.",
        input: "ما درجة لينا؟",
        tools: [find_student],
        max_steps: 5
    ) {
        Ok(a) => print(a.answer)
        Err(e) => print(e.kind())
    }
}
```

أنواع `find_student` تصبح الوصف الذي يراه النموذج، وتُفحص المعاملات قبل تشغيل دالتك.

## الوكلاء مع أدوات MCP والموافقات

`agent.run` تضيف أدوات من خوادم MCP (مذكورة في `elomar.toml`)، ودالة في كودك توافق
على الأفعال الخطرة، وسجلًا لكل خطوة:

```text
agent.run<Answer>(
    model: "assistant",
    instructions: "رتّب ملاحظاتي.",
    input: request,
    mcp: ["notes"],
    require_approval: ["notes.delete_all"],
    approve: |call| ask_user(call.tool),
    on_step: |step| print("خطوة: {step.tool} موافقة={step.approved}")
)
```

قرار السماح بفعل خطر يتخذه كودك، لا نص التعليمات. راجع
[`examples/agents`](https://github.com/abobasel86/elomar-lang/tree/main/examples/agents).
