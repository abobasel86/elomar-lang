# 3. الشروط والتكرار والدوال

## if و else

```elomar
fn main() {
    let الحرارة = 31
    if الحرارة > 30 {
        print("حار")
    } else if الحرارة > 15 {
        print("معتدل")
    } else {
        print("بارد")
    }
}
```

الشرط يجب أن يكون `Bool`. واجمع الشروط بـ `&&` (و) و`||` (أو) و`!` (ليس).

## match: الاختيار بين حالات كثيرة

```elomar
fn main() {
    let اليوم = "الجمعة"
    let النوع = match اليوم {
        "الجمعة" => "عطلة"
        "السبت" => "عطلة"
        _ => "يوم عمل"
    }
    print(النوع)
}
```

`_` تطابق أي قيمة أخرى. ويجب أن يغطي `match` كل الحالات، وإن نسيت حالة ينبهك الفحص.
ولاختيار قيمة من اثنتين استخدم `match` على `Bool`:

```elomar
fn main() {
    let العمر = 20
    print(match العمر >= 18 {
        true => "بالغ"
        false => "قاصر"
    })
}
```

ويمكن لعدة حالات أن تشترك في فرع واحد بـ `|`، وللأعداد الصحيحة أن تطابق نطاقًا:

```elomar
fn main() {
    let اليوم = "السبت"
    print(match اليوم {
        "الجمعة" | "السبت" => "عطلة"
        _ => "يوم عمل"
    })
    let الدرجة = 84
    print(match الدرجة {
        90..=100 => "ممتاز"
        70..90 => "جيد"
        _ => "استمر"
    })
}
```

`70..90` يشمل 70 ولا يشمل 90، و`90..=100` يشمل الطرفين.

## التكرار

```elomar
fn main() {
    for i in 1..4 {          // 1، 2، 3
        print(i)
    }
    for i in 1..=3 {         // 1، 2، 3 (يشمل النهاية)
        print(i * i)
    }
    for الفاكهة in ["تفاح", "تين"] {
        print("أحب ال{الفاكهة}")
    }
    var n = 3
    while n > 0 {
        print(n)
        n -= 1
    }
}
```

`break` تخرج من الحلقة، و`continue` تنتقل إلى الدورة التالية.

## الدوال

```elomar
fn المساحة(الطول: Float, العرض: Float) -> Float {
    return الطول * العرض
}

fn رحّب(الاسم: String) {
    print("أهلًا يا {الاسم}")
}

fn main() {
    print(المساحة(2.0, 3.5))
    رحّب("عمر")
}
```

لكل معامل نوع. و`-> Float` نوع النتيجة؛ والدالة بلا `->` لا تعيد شيئًا.

### الاستدعاء بالأسماء

يمكن تسمية المعاملات عند الاستدعاء، وهذا يوضح المعنى عندما تكثر:

```elomar
fn order(item: String, count: Int) -> String {
    return "{count} × {item}"
}

fn main() {
    print(order(count: 2, item: "قهوة"))
}
```

## تمرين

اكتب الدالة `fn grade(score: Int) -> String` التي تعيد `"ممتاز"` من 90 فأعلى،
و`"جيد"` من 70، و`"ناجح"` من 50، و`"راسب"` لما دون ذلك. ثم اطبع التقدير لـ 95 و72 و40.
