# 2. القيم والمتغيرات والنصوص

## أسماء للقيم

`let` تعطي اسمًا لقيمة لا تتغير بعد ذلك:

```elomar
fn main() {
    let المدينة = "عمّان"
    let السنة = 2026
    print(المدينة, السنة)
}
```

وعندما تحتاج قيمة تتغير استخدم `var`:

```elomar
fn main() {
    var النقاط = 10
    النقاط = النقاط + 5
    النقاط += 1
    print(النقاط)
}
```

استخدام `let` أولًا يجعل البرنامج أسهل فهمًا: تعرف أن القيمة ثابتة.

## الأنواع الأساسية

| النوع | أمثلة | ملاحظات |
|---|---|---|
| `Int` | `42`، `-7` | أعداد صحيحة |
| `Float` | `3.14`، `2.0` | أعداد عشرية |
| `Bool` | `true`، `false` | نعم أو لا |
| `String` | `"مرحبا"` | نص |
| `Duration` | `500ms`، `10s`، `2m` | مدد زمنية |

نادرًا ما تحتاج كتابة نوع المتغير، فاللغة تستنتجه. ويمكنك كتابته عندما يوضح المعنى:

```elomar
fn main() {
    let السعر: Float = 9.5
    let العدد: Int = 3
    print(السعر * to_float(العدد))
}
```

## الأعداد

```elomar
fn main() {
    print(7 / 2)        // 3.5: القسمة `/` تعطي دائمًا Float
    print(7 div 2)      // 3: قسمة صحيحة
    print(7 % 2)        // 1: باقي القسمة
    print(2.pow(10))    // 1024
    print(3.14159.round_to(2), 2.5.round())
}
```

إذا كبر عدد `Int` أكثر من سعته يتوقف البرنامج بخطأ واضح، ولا يعطي نتيجة خاطئة بصمت.

## النصوص

```elomar
fn main() {
    let الاسم = "Elomar"
    print(الاسم.length)                  // 6
    print(الاسم.upper(), الاسم.lower())
    print("  مسافات  ".trim())
    print("أ,ب,ج".split(","))            // ["أ", "ب", "ج"]
    print(الاسم.contains("lo"), الاسم.starts_with("E"))
    print("ها".repeat(3), "مرحبا".slice(0, 3))
}
```

`length` تعدّ الحروف كما تراها، فـ `"مرحبا".length` تساوي 5.

### إدراج القيم في النصوص

```elomar
fn main() {
    let المشروب = "شاي"
    let الأكواب = 3
    print("{الأكواب} أكواب {المشروب} بسعر {الأكواب * 2} دنانير")
}
```

لكتابة قوس حقيقي داخل النص ضع قبله شرطة مائلة: `"\{"`. وهذا مفيد مع JSON:

```elomar
fn main() {
    let n = 5
    print("\{\"count\": {n}\}")
}
```

## التحويل بين الأنواع

```elomar
fn main() {
    print(to_string(42) + "!")
    print("12".parse_int())       // Some(12)
    print("abc".parse_int())      // None: ليس عددًا
    print(to_int(3.9), to_float(2))
}
```

`parse_int` تعيد `Option`: إما `Some(العدد)` أو `None`. الدرس 5 يشرح التعامل مع الحالتين.
